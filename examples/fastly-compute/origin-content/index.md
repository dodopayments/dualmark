## Overview

This is the markdown twin served securely via Fastly Compute. It provides an AI-friendly, token-optimized representation of the root page.

## FAQ

### How does content negotiation work?
The Fastly Compute adapter intercepts requests from known AI bots and serves this markdown representation instead of the standard HTML payload.

### Why is this important?
Providing well-structured markdown ensures that Large Language Models can accurately digest and index site content without parsing DOM trees.
